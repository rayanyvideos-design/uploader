El Porqué de Todo Uploader

Private upload tool for the YouTube channel El Porqué de Todo.

What it is

El Porqué de Todo is a Spanish-language channel of short animated videos that explain everyday curiosities for a family audience (science, animals, the human body, space, technology). Every video is original: script, cartoon animation, narration and music are made for the channel.

This App is a desktop tool used only by the channel owner on their own computer. Once a video is finished, the App uploads it to the owner's own YouTube channel using the YouTube Data API (videos.insert), with its title, description, tags, category and publish time, so the channel can publish on a regular schedule (three short videos a day).

How it uses Google data

  • Requests a single OAuth scope, https://www.googleapis.com/auth/youtube.upload, from the channel owner.
  • Uploads only the owner's own original videos to the owner's own channel. It never accesses other users' accounts.
  • Reads the public "most popular" chart for Spain with an API key, to find topic ideas.
  • Stores tokens only on the owner's computer. No server, no database, no sharing with third parties.
