Privacy Policy

Last updated: 24 November 2026

El Porqué de Todo Uploader ("the App") is a private desktop tool used only by the owner of the YouTube channel El Porqué de Todo to upload the channel's own original short videos to that same channel. The App has no public users, no sign-up and no website functionality besides this page.

What data the App accesses

  • YouTube API Services. With the channel owner's permission (Google OAuth scope youtube.upload), the App uploads videos and sets their title, description, tags, category, privacy status and publish time. It reads only the ID and status of the videos it uploads.
  • Public YouTube data. With an API key, the App reads the public list of trending videos in Spain (titles, channel names and view counts) to get ideas for new topics. No personal data of other users is collected.

How the data is stored

  • The OAuth access and refresh tokens are stored only on the owner's own computer, in a local file. They are never sent to any server other than Google's.
  • The App does not have its own server or database. It does not sell, share, transfer or disclose any data to third parties.
  • The App does not use data for advertising and does not track anyone.

How to revoke access

Access can be revoked at any time from the Google security settings page: https://security.google.com/settings/security/permissions. Deleting the local token file also removes all stored access.

YouTube and Google

The App uses YouTube API Services. By using it you agree to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

Política de privacidad

El Porqué de Todo Uploader (la "App") es una herramienta privada de escritorio que usa únicamente el propietario del canal de YouTube El Porqué de Todo para subir los vídeos cortos originales del canal a ese mismo canal. No tiene usuarios públicos ni registro.

  • Servicios de la API de YouTube: con permiso del propietario (ámbito OAuth youtube.upload) la App sube vídeos y fija su título, descripción, etiquetas, categoría, privacidad y hora de publicación. Solo lee el identificador y el estado de los vídeos que sube.
  • Datos públicos: con una clave de API lee la lista pública de vídeos en tendencia en España (títulos, canales y visitas) para buscar ideas de temas.
  • Los tokens de acceso se guardan solo en el ordenador del propietario. La App no tiene servidor ni base de datos y no comparte, vende ni cede datos a nadie.
  • Se puede revocar el acceso en https://security.google.com/settings/security/permissions.
  • Al usar la App aceptas las Condiciones del Servicio de YouTube; consulta también la Política de Privacidad de Google.
